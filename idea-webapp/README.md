# 휴게소 아이디어 생성기 (React + Vite)

관련 문서: `../웹앱_개발계획.md`, `../BRD.md`, `../PRD.md`, `../최종프롬프트_아이디어카드_기획안.md` (v2)

## 현재 상태 (2026-11-18): 개발 계획 1단계 — 화면 뼈대
- 접속 코드 → 입력 → 생성 → 결과(카드 5개 / 선정 결과 / 초안 탭 + 본문·붙임 복사 / 점검표) 흐름이 동작합니다.
- **AI는 아직 연결되지 않았습니다.** `/api/generate`는 가상 샘플(`server/sampleResult.js`)을 돌려줍니다. AI 제공사(D1)가 정해지면 `server/devApi.js`의 생성 부분을 실제 호출로 바꿉니다.

## 기사 검색 범위 (2026-11-18 결정, 웹앱에만 적용)
- **네이버 뉴스, 기준일(입력한 오늘 날짜)로부터 최근 3개월.** 해외 사례는 국내 언론의 해외 보도로 대신합니다.
- 설정·기간 계산: `server/searchScope.js` (예: 2026-05-31 기준 → 2026-02-28 ~ 2026-05-31)
- 실제 검색은 2단계에서 네이버 검색 API(뉴스)로 연결합니다. 키는 `.env`의 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` (`.env.example` 참고)

## 실행
```bash
npm install
npm run dev
```
터미널에 표시되는 `Network: http://192.168.x.x:5173/` 주소로 같은 네트워크의 다른 PC(옆자리)에서 접속할 수 있습니다. 앱 화면 맨 아래에도 "옆자리 접속 주소"가 표시됩니다.

- 다른 PC에서 접속이 안 되면 Windows 방화벽이 5173 포트를 막고 있을 수 있습니다. 방화벽 설정은 PC 관리 권한·사내 규정에 따라 처리하세요.
- 이 주소는 **개발용**입니다. 이 PC가 켜져 있고 `npm run dev`가 실행 중일 때만 접속됩니다.

## 접속 코드
- `.env` 파일의 `ACCESS_CODE` 값입니다 (형식은 `.env.example` 참고). `.env`는 git에 올리지 않습니다.
- 값을 바꾸면 개발 서버를 다시 시작하세요.
- `VITE_` 접두사를 붙이지 마세요. 붙이면 브라우저 코드에 노출됩니다.

## 구조
```
server/devApi.js        개발용 API (접속 코드 확인, 샘플 결과, 네트워크 주소)
server/sampleResult.js  가상 샘플 결과 (v2 출력 구성, 날짜는 기준일 3개월 이내)
server/searchScope.js   검색 범위 설정 (네이버 뉴스, 최근 3개월)과 기간 계산
src/App.jsx             화면 흐름
src/components/         AccessGate(접속), InputForm(입력), Results(결과)
src/format.js           초안·붙임을 개조식 텍스트로 변환, 복사(비보안 주소용 대체 방식 포함)
```
